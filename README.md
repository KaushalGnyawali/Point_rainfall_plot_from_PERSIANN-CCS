# Point_rainfall_plot_from_PERSIANN-CCS
This script plots rainfall time series of a location from PERSIANN-CCS data downloaded as a .csv file from the CHRS Data portal (https://chrsdata.eng.uci.edu/). Download the csv file for a point location and save it in the same folder as this script. Then run the script. The script generates a plot of rainfall time series from the CSV file.
